【WZ. V11.2 · 三首钢琴曲离线循环版】

一、打开网站
1. 右键下载的 ZIP 压缩包，选择「全部解压缩」。
2. 打开解压后的文件夹，双击 index.html（建议使用 Chrome 或 Microsoft Edge）。
3. 不要直接在压缩包预览窗口中运行网页，也不要只拷贝单个 HTML 文件。
4. 这一版本是本地静态网站，未部署为公网网址。

二、音乐播放器（离线）
播放器位于各页面左下角，点击 ♫ 开始播放。支持暂停 / 继续、上一首 / 下一首、音量调节、播放列表选歌、拖动播放进度。
播放顺序如下，自动无限循环：
  01 · 夜的钢琴曲五 — Rorik 钢琴演奏版
  02 · 梦中的婚礼 — LucySPA 钢琴演奏版
  03 · Merry Christmas, Mr. Lawrence — Chihiro Todo 钢琴演奏版
第三首结束后，自动返回第一首。三个 MP3 已打包在 assets/music 目录内，无需联网。
浏览器限制未经点击的有声自动播放，第一次打开网站需主动点击一次播放。
跨网页跳转时，播放器记录所在曲目和时间，尝试恢复播放；有声续播能否自动成功由浏览器决定。
原版 MP3 归属各自演奏者，本网站只保留用户上传的音频文件及其演奏者标注。

四、说明
个人批注、阅读进度以及其他浏览器本地记录不会自动同步到其他设备。
若发现音频无法播放，请确认 index.html 所在目录下有 assets/music 文件夹及三个 MP3，且浏览器允许页面播放声音。

V11.2 仅升级播放器为三曲循环，原有网页、照片和交互均保留。
