# Generated aquatic leaf surface texture

`aquatic-leaf-generated.webp` is an AI-generated green leaf-vein surface image
created for WZ. Personal Archive using OpenAI's image-generation tool on
2026-10-14. It is a full-bleed surface colour image used on original curved 3D
plant blade meshes, with a very small bump contribution. It contains no fish,
no aquarium photograph, no cutout alpha and no replacement fish geometry.

This file is an AI-generated texture asset, **not a photographed botanical scan**
and **not a Poly Haven CC0 texture**. The web copy is locally converted to WebP.
The existing CC0 licenses and source manifest for the photographed rock and
gravel materials remain in `LICENSES.md` and `SOURCE-MANIFEST.json` unchanged.

The root task retains the original generated image, request and exact output
record. The website loads the WebP from its own hosting directory, without a
remote image-generation API or CDN dependency.
