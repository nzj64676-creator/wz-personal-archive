04 — ON MY DESK

我的生活，不止一个标签。

学习、训练、阅读、数字探索与独处表达——我愿意反复投入时间的事情，比形容词更能说明我是谁。选择一个主题，进入我的日常。

LIVING FILE / LEARNING & THINKING

我不是在刷题。
我在追问答案如何成立。

数学给我的吸引力，不只是解出一道题，而是从定义、条件和逻辑关系中把它真正想通。学习是一种持续的认知训练，而不单是考试准备。

01 / 我的学习场景

把一个概念追问到底

我会观看课程，再用例题检验理解。遇到矩阵、伴随矩阵、二次型、微分方程或极限，我经常会问：“为什么可以这样变形？”如果某一步缺少解释，我宁愿停下来补齐逻辑，也不想靠记忆把整套步骤背下来。

02 / 方法论

先理解结构，再记住算法

我更喜欢把知识拆成定义、条件、关键定理、典型题型与变式。对于简单计算，我倾向于快速处理；对于决定解题方向的推理，则希望讲清楚。这接近深层学习（Deep Learning，指学习心理学中的深层加工，不等于机器学习里的深度学习）的思路。

03 / 反馈

每次不懂都是检查认知模型的机会

在某道线性代数题里卡住时，我会回头检查是矩阵变换的规则不清楚，还是没有理解秩、主元与自由变量的关系。看懂之后，我会总结做题顺序，把局部错误整理成可迁移的方法。

04 / 我的期待

从解题能力走向建模能力

我也希望逐步把抽象数学与工程问题联系起来：当一个现实问题可以用变量、约束和方程描述时，如何建立可靠模型？我还在学习阶段，不急于把兴趣包装成专业能力。

“我想得到的不是一个标准答案，而是能让我自己再次推导的理解。”

LIVING FILE / MOVEMENT & TRAINING

训练不是拼命。
我想知道身体如何变强。

跑步与力量训练帮助我建立可观察的目标，也让我意识到身体并不总按计划运作。我会记录表现，更会关心疲劳、恢复和动作质量。

跑步训练抗阻运动恢复与适应

01 / 跑步

比配速更有意思的，是配速背后的身体反应

在不同距离和强度的跑步中，我会注意节奏、呼吸、步幅和腿部疲劳。有时呼吸还算从容，腿却已经感觉沉重；有时前段跑得顺利，后段动作开始变形。我会追问这些感觉分别反映了什么，而不是简单用“够不够拼”解释。

02 / 力量

从重复次数走向训练质量

我会进行哑铃弯举、负重深蹲等基础抗阻训练，并关注重量、组数、重复次数及剩余重复次数（Reps in Reserve）。与一味追求做更多相比，我更希望理解渐进超负荷（Progressive Overload）和动作质量之间的平衡。

03 / 恢复

表现下降，本身也是重要信息

训练后的沉重、局部酸痛或技术动作下降，都值得纳入训练反馈。训练适应需要负荷，也需要合理的恢复。现在我更愿意把身体状态当作真实的约束条件，而不是把任何疲劳都理解为意志问题。

04 / 训练态度

给自己目标，也允许过程调整

我会认真规划训练参数，也会根据实际完成情况评估计划是否合理。运动让我学到的，是目标、行动和反馈必须同时存在；一个真正可持续的计划，要考虑今天的状态，也要考虑长期的健康。

“我关心成绩，但更想弄明白：是什么让成绩发生变化。”

LIVING FILE / READING & IDEAS

我读书，
是为了获得新的解释。

阅读让我接触自己本来不会想到的视角。我尤其关注人的判断、群体影响、认知偏差，以及思想如何改变行为。

01 / 《思考，快与慢》

我们以为自己理性，判断却可能受到启发式影响

这本书让我开始留意快速直觉与审慎推理之间的关系。我会思考：自己是否过度自信？是否在使用容易想到的信息代替全面证据？它对我最大的启发不是“所有直觉都错误”，而是对判断过程多一点自我审视。

02 / 《乌合之众》

一个人进入群体以后，会发生什么？

群体心理、从众与情绪感染等问题对我很有吸引力。但我也不会把一本经典著作当成能够解释所有群体行为的定论。理解它的历史背景与学术局限，同样是阅读的一部分。

03 / 《影响力》

说服不是魔法，它有可分析的机制

我会关注社会认同、互惠、权威等影响机制怎样出现在广告、互联网平台或日常人际互动中。了解一种心理机制，不等于每次都能准确识别它；我更关心这些知识能否让自己做出更清醒的判断。

04 / 我的阅读方法

读完之后，把概念带回真实生活

如果书里出现认知偏差或社会影响的概念，我会尝试拿现实案例来检验：是否确实适用？有没有其他解释？对我而言，好的阅读不是记住术语，而是提高提出问题和辨别证据的能力。

“书不是用来证明我懂得多，而是帮助我看到自己原本看不到的部分。”

LIVING FILE / DIGITAL WORLD

我使用互联网，
不只为了消费内容。

从 AI 工具、GitHub 到金融平台与跨境支付，我喜欢理解数字基础设施怎样运作，也在摸索如何利用工具扩大信息获取与实践能力。

01 / AI

我把 AI 当作思考助手，而不是答案机器

我会让工具辅助理解数学步骤、整理知识框架、比较方案，也会继续追问答案的依据。模型输出可能出错，因此检验结果、识别未知和保持独立判断，比单纯追求生成速度更重要。

02 / 开发工具

好奇一个工具，就想知道它能做到哪一步

我会探索 C 语言、GitHub 和个人网站构建等数字工具。对我而言，从“会点开某个网站”到“自己能制作一个网站”，是把好奇心转化为实际作品的一种方式。

03 / 金融基础设施

支付方式与金融系统，也是我探索的对象

我在学习交易所、指数基金、ETF、国际支付网络和不同银行卡的使用条件。关注这些概念并不是宣称自己懂投资，而是希望理解不同系统之间如何连接、资金和信息在什么规则下流动。

04 / 信息生态

跨平台获得信息，也需要跨来源核实

我会接触中文与国际互联网不同平台，但并不认为渠道越多就自动越接近事实。来源可信度、内容背景、平台激励和信息偏差，都会影响我们最终看到什么。

“工具能扩大能力边界，但判断力仍然需要自己建立。”

LIVING FILE / SOLITUDE & EXPRESSION

我喜欢一个人的时间。
但我不喜欢想法无人分享。

这是我身上最容易被误解的一种反差：我可以享受独处，也有很强的表达欲。对我来说，私人空间与思想交流并不是对立的。

01 / 独处

我的安静，不等于空白

我可以独自看书、学习数学、运动，或者只是整理最近想过的问题。没有持续的社交安排，并不一定让我感到乏味；一个人反而容易集中注意力。

02 / 表达

想到一个新问题时，我很想说出来

有时只是路上看见一幕日常场景，我就会联想到未来的生活、教育或人与人之间的责任。那些突然出现的思考，常常让我想通过聊天分享出去。表达有时也能帮助我把模糊的想法变成清晰的观点。

03 / 交流偏好

我更在乎交流的内容，而不是不断保持热闹

我愿意讨论心理学、社会问题、技术、阅读，也愿意分享跑步和生活的小发现。我喜欢有回应、有论据、愿意互相理解的对话。轻松的聊天当然也可以有价值，我只是不认为社交必须是持续的表演。

04 / 对自己的认识

INTJ 是自述标签，不是我的全部

我会用 INTJ 来表达一种自我认同，但我不希望这个标签替代事实。能独处、爱表达、重视边界、愿意分享，可以同时成立。认识我，最好还是通过这些真实习惯与选择。

“独处让我拥有自己的节奏；交流让我遇见不同的世界。”

THREE EVERYDAY CONTRASTS
01

习惯追问

不懂一个公式，就回到定义；想不通一种现象，就寻找更多解释。不轻易让问题停在表面。

02

持续迭代

学习与运动都在复盘中更新：看见真实结果，调整方法，不把旧计划当成身份标签。

03

独处与表达

有自己的节奏，也愿意分享新观点。安静地学习，热烈地思考，两者并不矛盾。
