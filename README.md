# WZ. Personal Archive V11.2

个人 IP 网站的已检查静态源码。保留 17 个 HTML 页面、30 张本地图片、3 首本地 MP3，以及原版的说明文本和全部交互功能。

## 使用与部署

首页是仓库根目录的 `index.html`，其余页面和资源一并部署。纯 HTML、CSS、JavaScript，无需安装依赖、构建命令或服务器。`.nojekyll` 用于按原文件发布。

可将整个仓库根目录发布到支持静态文件的 HTTPS 托管平台。GitHub Pages 的上线状态不代表已经验证中国大陆免 VPN 访问；还需在大陆不同运营商网络实测。域名和大陆加速的要求以所选平台的官方说明为准。

## 访客交互

- 浏览器需要访客先点击左下角的音乐播放按钮；三首 MP3 位于 `assets/music/`，支持选歌、循环播放和进度跳转。
- 阅读进度、个人批注和其他记录使用 `localStorage`，每位访客、每个浏览器及每个网站域名分别保存，不会自动同步或共享。
- 资源使用本地相对路径，请完整保留 `assets/` 和 `dimensions/` 目录。

根目录的 `README_使用说明.txt` 和 `部署指南_腾讯云EdgeOne.txt` 是原包说明，原样保留。其中“未部署”描述的是原始离线版本，不代表当前的托管状态。

## 互动金鱼缸开发预览

此开发分支新增 `aquarium.html`，以及“理想生活”中的延迟加载鱼缸入口。五尾真实骨骼金鱼、投喂/进食、夕阳/夜色、图鉴和沉浸观察见 [第二阶段说明](AQUARIUM_PHASE2.md)。本地需要通过 HTTP 服务打开，并使用支持 WebGL 2 的浏览器。渲染库、模型和贴图都保存在 `assets/`，无需外部 CDN。

此分支仍用于验收，没有替换 main 的正式站点。原始单鱼验证保存在 `aquarium-phase1.html`。模型作者署名、许可和校验记录见 [模型授权说明](assets/aquarium/models/ATTRIBUTION.md)。
