IF YOU ONLY READ ONE THING

只看三句话，也能认识这一面的我。

01会把学习知识点拆成题型和具体练习。↗02跑步训练会关注距离、组数、配速与间歇。↗03有目标，也愿意根据实际反馈修正计划。↗

我习惯将想做的事转换为相对具体的目标，再思考实现目标所需要的路径、时间和资源。我重视计划，但并不把计划当成不可调整的命令；反馈与现实条件同样重要。

CHAPTER 01

“变优秀”太模糊，我更喜欢可操作的目标

GOAL SETTING

对于学习、未来发展和体育训练，我倾向于把模糊的愿望变成更清晰的目标。比如希望提高某项能力时，我会追问具体需要改进哪部分、现在处于什么水平、如何判断是否真的有进步。

我对目标设定（Goal Setting）的理解，不只是确定终点，还包括设计达成目标的过程。只有将目标转化为可以执行、可以检查的行动，它才会真正改变日常安排。

面对某个新的学习主题，我会先问：核心概念是什么？常见考法有哪些？哪些步骤值得反复练习？我希望最终拥有一套可复用的问题处理顺序。这与目标分解（Goal Decomposition）接近：把抽象方向拆成可观察、可检查的阶段成果，而不是把“努力”作为唯一尺度。

CHAPTER 02

制定计划之后，我更看重实际执行

IMPLEMENTATION

在学习方面，我会围绕需要掌握的知识点安排课程、例题、练习与复盘；在训练方面，我会关心距离、组数、间歇、配速和恢复之间的关系。这些具体参数帮助我把抽象的“努力”落实到行动。

执行意图（Implementation Intention）强调预先明确在什么情境下采取什么行动。我对这类方法感兴趣，因为单靠意愿往往不足以维持长期投入。

运动会暴露计划与现实之间的差距。即使原本设计了间歇跑或力量训练，当实际腿部疲劳、动作质量与预期不一致时，也需要调整。我关注配速、组数、休息时长，不是为了数字本身，而是因为具体参数让行动可比较、可复盘。

CHAPTER 03

计划不是圣旨：反馈出现时就应该更新

FEEDBACK LOOP

计划不是为了证明我一开始的判断正确。如果执行结果与预期出现偏差，我更愿意分析方法是否存在问题，再决定调整强度、节奏或优先级。

这种过程接近反馈控制（Feedback Control）：设定目标、观察现状、比较差距并修正行动。在真实生活里，反馈有时不完整或带有噪声，因此我也希望避免因为某一次表现而过度调整。

我不喜欢一旦定了计划就不许讨论的思路。数学题卡住了，可以回到定义重新理解；训练效果和预期不符，可以复盘强度分配、恢复与动作状态。策略修正（Adaptive Planning）是保持目标不变、允许实现路径变化，并在必要时重新审视目标本身。

CHAPTER 04

长线方向感，与短线灵活性可以共存

TRADE-OFFS

升学、技术学习、运动、阅读和未来生活规划，都在争夺有限的时间与精力。目标之间可能存在竞争，所以我会考虑优先级与机会成本（Opportunity Cost）：投入一个方向，意味着需要暂时减少另一个方向的投入。

我希望自己对长期发展有方向感，也保留根据新信息改变路线的空间。目标导向对我而言不是固执地坚持一个计划，而是清楚自己为什么行动。

我会思考未来学习方向与专业发展，也会关注财务自主、时间配置和技术能力。长期目标不是为了提前写死每一年，而是让眼前选择有一个参考坐标。机会成本（Opportunity Cost）提醒我：每一次投入都意味着暂时放弃别的可能性，所以选择比单纯增加任务更重要。

“目标不是用来展示决心的，而是用来指导每一次具体选择的。”
A REAL EXAMPLE · 真实细节

一个能说明我的例子

我会在一次训练前问清楚每组跑多远、目标配速、组间休息多久；结束后又追问腿部疲劳说明了什么。目标对我而言不是一句口号，而是一组可以被执行和检验的动作。

IDEAS BEHIND THE WORDS

术语笔记 / Glossary

目标设定 Goal Setting

将期望结果明确为可追踪目标，并使其能够指导行动。

执行意图 Implementation Intention

将行为与具体情境关联的“如果—那么”行动计划。

反馈控制 Feedback Control

根据目标与实际状态的差距持续调整行动的控制过程。

机会成本 Opportunity Cost

作出选择时被放弃的最有价值的替代选项的收益。
